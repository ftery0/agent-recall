# Contributing

Issues and pull requests are welcome.

- Run `go vet ./...`, `go test ./...` and `go test -race ./...` before opening a pull request.
- Keep to the standard library where you can, and avoid new layers or wrappers.
- Never commit real transcripts, records, databases or personal settings. Tests use synthetic data only.

By contributing, you agree that your contribution is licensed under the [PolyForm Noncommercial License 1.0.0](LICENSE), the same as the rest of the project.
